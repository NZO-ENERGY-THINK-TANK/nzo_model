# data/

נתוני הבסיס של המודל, בקבצי CSV. **ערכים בלבד** (בלי נוסחאות).

| קובץ | מקור בגליון | תוכן |
|---|---|---|
| `costs.csv` | `05_costs` עמודות A–N, שורה 1 = כותרת, שורות 2–56 (כל הלשונית נטענת מה-CSV) | הנחות עלות: מוצר, פרמטר, מקור, יחידות, הערות, שיטת שינוי, מחיר בסיס, ושינוי באחוזים לכל שנה 2022–2050 |
| `yearly_demand.csv` | `02_demand` כולה (A1:C29, טעינה מלאה), מקור: תחזית נוגה | תחזית ביקוש שנתית 2023–2050 (נוגה 2023) |
| `must_run_yearly.csv` | טבלה חדשה, לשונית `03_must_run_yearly` (טעינה מלאה); הערכים נלקחו מ-`03_future-yearly-demand!G` (`SUM(C:F)`) | קיבולת must run שנתית (MW), 2023–2050 |
| `hourly_demand23.csv` | `04_raw-data-hourly` כולה (A1:N8761, טעינה מלאה), מקור: דו"ח מצב משק החשמל | פרופיל שעתי של שנת ייחוס 2023 (8,760 שעות) |

שלושת הקבצים יוצאו: `yearly_demand.csv`, `hourly_demand23.csv`, `costs.csv`. `01_parameters` הוא קלט ספציפי להרצה (לא הנחות בסיס), ולכן נשאר בגיליון ולא ב-git. `20_roadmaps-input` לא יוצאה. פרטי העמודות, היחידות והמקורות בסעיפים למטה.

כל שינוי בקבצים אלה הוא Pull Request עם אישור של שני מאשרים.

## yearly_demand.csv

**מקור:** תחזית נוגה 2023 (גיליון חיצוני בתיקיית ה-Drive, לשונית `agg_years`, נתונים שעתיים עד 2050 המסוכמים לרמה שנתית). שני תרחישים: שמרני ו-BAU.

| עמודה | יחידה | הסבר |
|---|---|---|
| `year` | שנה | 2023–2050 (28 שורות) |
| `noga23_conservative_twh` | TWh | ביקוש, תרחיש שמרני של נוגה (`02_demand!B`) |
| `noga23_bau_twh` | TWh | ביקוש, תרחיש BAU של נוגה (`02_demand!C`) |

המקור המקורי היה IMPORTRANGE מגיליון חיצוני (`agg_years`). בגליון `02_demand` הנוכחי יש רק את ה-CSV (A1:C29). ב-`03_future-yearly-demand` עמודות P ו-Q מחפשות לפי שנה ב-02. הערכים מיוצאים בדיוק של כ-10 ספרות משמעותיות.

## must_run_yearly.csv

שתי עמודות: `year` (2023–2050, 28 שורות) ו-`must_run_mw`: 600 עד 2039 ו-0 מ-2040. הערכים זהים למה שחושב ב-`03_future-yearly-demand!G` (סכום must run מפחם, ייצור משולב, מיקרו-ייצור ומתקנים בילטרליים; בשנים האלה רק הפחם נותר). הקוד קורא אותם ל-`mustRun` לכל שנה (`futureDemandForecast`). מקור הנתון המקורי: **להשלמה**.

## hourly_demand23.csv

**מקור:** דו"ח מצב משק החשמל, 2023 (לפי `00_documentation` בגיליון). קישור, תאריך הורדה והגדרת היחידות: **להשלמה**.

8,760 שורות (שעה בשעה, 2023) + כותרת. ערכים בלבד. המספרים ללא פסיקי אלפים; `gas_share` כשבר (0.80 = 80%). יחידות ההספק: MW (הנחה, לאימות).

| עמודה | עמודה בגיליון המקורי | הסבר |
|---|---|---|
| `day`, `month`, `year` | B, C, D | תאריך (שעון מקומי, כולל מעבר שעון קיץ) |
| `time` | F | שעה ביום |
| `hour_of_year` | G | 1–8760 |
| `total_generation_mw` | H | סך יצור חשמל |
| `must_run_mw` | K | must run |
| `solar_mw` | L | סולארי |
| `gas_mw` | M | גז |
| `fossil_mw` | N | פוסילי |
| `gas_share` | O | אחוז השימוש בגז טבעי |
| `wind_mw` | P | רוח |
| `other_renewables_mw` | Q | אחר מתחדשות |
| `other_mw` | R | אחר |

הגיליון `04_raw-data-hourly` נטען כעת כולו מהקובץ (14 עמודות, כותרת בשורה 1, A1 = `day`), והעמודות הישנות A, E, I, J לא קיימות בו. הקוד (`_readRefYearHoursData`) קורא רק את המבנה הזה. נוסחאות ב-`01_parameters` (C4, C5, C7) מפנות לעמודות H, L, F.

לא יוצאו: `Date String` (A, ריקה ברובה), `Date` (E, כפולה לתאריך), "אורות רבין" ו"רוטנברג" (I, J, ריקות לגמרי). 

## costs.csv

מקור: לשונית `05_costs` (הערכות ומחקרים, בהם Bloomberg, לפי `00_documentation`). עמודות A–N (כותרת + 55 שורות אחרי הסרת שורות מחושבות ויחסי ה-PV). ערכים בלבד, בדיוק מלא (השבר: 0.06 = 6%).

| עמודה | עמודה בגיליון המקורי | הסבר |
|---|---|---|
| `product`, `parameter`, `source`, `units`, `comments` | A–E | מזהה השורה ותיאורה |
| `increase` | F | שיטת ההרחבה בין השנים: `linear`, `yoy`, `none` |
| `base_price` | G | מחיר/ערך בסיס |
| `pct_change_2022`, `pct_change_2025`, `pct_change_2030`, `pct_change_2035`, `pct_change_2040`, `pct_change_2045`, `pct_change_2050` | H–N | שינוי יחסי לעומת `base_price` בכל שנה (שבר, -0.162 = ירידה של 16.2%). משמש `increase` ל-`linear`/`yoy` |

הערות:
- G13, G26, G35 היו נוסחאות (`=G7`, `=125*C75`, `=C78`) והוחלפו בערכים.
- לא יוצאו עמודות O–U (ערכי התחזית המחושבים: `base_price × (1 + pct_change)`). הנוסחאות נשארות בגיליון.
- שורות `share-of-deployment` (יחס ההתקנה בין סוגי ה-PV) הוסרו מהקובץ: היחסים הם קלט של ה-roadmap (`30_roadmaps-keyframes`, עמודות `pvShare*`), לא נתון עלות.
- הוסרו שורות מחושבות: `PV-Average` (שורות 19–22 בגיליון: share, capex, opex, lifetime) ו-`emissions combined` (שורה 41, לא נקראת בקוד).
- `pv-average` (capex, opex, lifetime) מחושב בקוד (`YearState.pvAverage`): ממוצע משוקלל של ארבעת סוגי ה-PV לפי היחסים של ה-roadmap בכל שנה.

הערות ל-`costs.csv`: הקוד מחשב `base_price × (1+pct)` בעצמו (אין עמודות מחושבות בגיליון). בכל טעינה, `05_costs` מוחלפת כולה ("Replace current sheet") והכותרת בשורה 1. כלל PV-Dual-Use: capex = capex של dual-use + capex של pv-commercial (מחושב ב-`pvAverage`).
