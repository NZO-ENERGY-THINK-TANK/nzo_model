# data/

נתוני הבסיס של המודל, בקבצי CSV. **ערכים בלבד** (בלי נוסחאות).

| קובץ | מקור בגליון | תוכן |
|---|---|---|
| `costs.csv` | `05_costs` עמודות A–N, שורות 2–66 | הנחות עלות: מוצר, פרמטר, מקור, יחידות, הערות, שיטת שינוי, מחיר בסיס, ושינוי באחוזים לכל שנה 2022–2050 |
| `yearly_demand.csv` | `02_demand` עמודות L, M (שורות 20–47), מקור: תחזית נוגה | תחזית ביקוש שנתית 2023–2050 (נוגה 2023) |
| `hourly_demand23.csv` | `04_raw-data-hourly`, מקור: דו"ח מצב משק החשמל | פרופיל שעתי של שנת ייחוס 2023 (8,760 שעות) |

שלושת הקבצים יוצאו: `yearly_demand.csv`, `hourly_demand23.csv`, `costs.csv`. `01_parameters` הוא קלט ספציפי להרצה (לא הנחות בסיס), ולכן נשאר בגיליון ולא ב-git. `20_roadmaps-input` לא יוצאה. פרטי העמודות, היחידות והמקורות בסעיפים למטה.

כל שינוי בקבצים אלה הוא Pull Request עם אישור של שני מאשרים.

## yearly_demand.csv

**מקור:** תחזית נוגה 2023 (גיליון חיצוני בתיקיית ה-Drive, לשונית `agg_years`, נתונים שעתיים עד 2050 המסוכמים לרמה שנתית). שני תרחישים: שמרני ו-BAU.

| עמודה | יחידה | הסבר |
|---|---|---|
| `year` | שנה | 2023–2050 (28 שורות) |
| `noga23_conservative_twh` | TWh | ביקוש, תרחיש שמרני של נוגה (`02_demand!L`) |
| `noga23_bau_twh` | TWh | ביקוש, תרחיש BAU של נוגה (`02_demand!M`) |

המקור בגיליון הוא IMPORTRANGE מגיליון חיצוני (`agg_years`). הנוסחה מתועדת כטקסט ב-`02_demand!L19` ו-`M19`. הערכים מיוצאים בדיוק של כ-10 ספרות משמעותיות.

## hourly_demand23.csv

**מקור:** דו"ח מצב משק החשמל, 2023 (לפי `00_documentation` בגיליון). קישור, תאריך הורדה והגדרת היחידות: **להשלמה**.

8,760 שורות (שעה בשעה, 2023) + כותרת. ערכים בלבד. המספרים ללא פסיקי אלפים; `gas_share` כשבר (0.80 = 80%). יחידות ההספק: MW (הנחה, לאימות).

| עמודה | עמודה בגיליון | הסבר |
|---|---|---|
| `day`, `month`, `year` | B, C, D | תאריך (שעון מקומי, כולל מעבר שעון קיץ) |
| `time` | F | שעה ביום |
| `hour_of_year` | G | 1–8760 |
| `total_generation_mw` | H | סך יצור חשמל |
| `must_run_mw` | K | must run |
| `solar_mw` | L | סולארי |
| `gas_mw` | M | גז |
| `fossil_mw` | N | פוסילי |
| `gas_share` | O | אחוז השימוש בגז טבעי |
| `wind_mw` | P | רוח |
| `other_renewables_mw` | Q | אחר מתחדשות |
| `other_mw` | R | אחר |

לא יוצאו: `Date String` (A, ריקה ברובה), `Date` (E, כפולה לתאריך), "אורות רבין" ו"רוטנברג" (I, J, ריקות לגמרי). הקוד קורא את העמודות B, C, D, F, G, H, L, N, P בלבד.

## costs.csv

מקור: לשונית `05_costs` (הערכות ומחקרים, בהם Bloomberg, לפי `00_documentation`). עמודות A–N, שורות 2–66 (כותרת + 59 שורות אחרי הסרת שורות מחושבות). ערכים בלבד, בדיוק מלא (השבר: 0.06 = 6%).

| עמודה | עמודה בגיליון | הסבר |
|---|---|---|
| `product`, `parameter`, `source`, `units`, `comments` | A–E | מזהה השורה ותיאורה |
| `increase` | F | שיטת ההרחבה בין השנים: `linear`, `yoy`, `none` |
| `base_price` | G | מחיר/ערך בסיס |
| `pct_change_2022`, `pct_change_2025`, `pct_change_2030`, `pct_change_2035`, `pct_change_2040`, `pct_change_2045`, `pct_change_2050` | H–N | שינוי יחסי לעומת `base_price` בכל שנה (שבר, -0.162 = ירידה של 16.2%). משמש `increase` ל-`linear`/`yoy` |

הערות:
- G13, G26, G35 היו נוסחאות (`=G7`, `=125*C75`, `=C78`) והוחלפו בערכים.
- לא יוצאו עמודות O–U (ערכי התחזית המחושבים: `base_price × (1 + pct_change)`; בשורות `share-of-deployment` הן קלט, ראו להלן). הנוסחאות נשארות בגיליון.
- שורות 15–18 (`share-of-deployment`): `base_price` מכיל את ערך 2025 (עמודה P בגיליון; 2025–2050 קבועים, ב-2022 ערכים אחרים: 0.285, 0.31, 0.225, 0.18).
- הוסרו שורות מחושבות: `PV-Average` (שורות 19–22 בגיליון: share, capex, opex, lifetime) ו-`emissions combined` (שורה 41, לא נקראת בקוד).
- **לביצוע:** `pv-average` capex, opex ו-lifetime נקראים בקוד (`year-state.js`) ולכן צריך לכתוב פונקציה שמחשבת אותם (ממוצע משוקלל לפי ה-`share-of-deployment`) במקום הנוסחאות בגיליון, לפני שמחליפים את `05_costs` בקובץ.
